# Spark

🔥 Aplicativo de organização de eventos e encontros em parques

> **Documentação completa**: [docs/README.md](docs/README.md)

## Estrutura do Projeto

```
Spark/
├── src/               # Código fonte
│   ├── php/          # Scripts PHP
│   ├── css/          # Estilos
│   └── pages/        # Páginas HTML
├── database/          # Scripts SQL
├── public/            # Arquivos públicos
│   ├── assets/       # Imagens, ícones
│   └── uploads/      # Uploads de usuários
├── features/          # Módulos/telas da aplicação
└── docs/              # Documentação
```

## Início Rápido

1. Configure o banco de dados usando os scripts em `database/`
2. Configure a conexão em `src/php/conexao.php`
3. Acesse via `src/php/index.php`

Para mais detalhes, consulte a [documentação completa](docs/README.md).
